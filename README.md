# Vulpes Ignis — Public Website

This public repository holds the visitor-facing static website only. Unpublished manuscripts, internal content inventories, and development files remain in the private source repository.

**GitHub Pages URL:** https://therealtenkoshi2020.github.io/vulpes-ignis-site/

## Hosting

In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save. GitHub Pages serves the root `index.html` and the relative `assets/`, JavaScript, and CSS files without requiring visitors to sign in.

The site is intended for adults 18+ and offers educational content and private, session-based reflection tools. It is not medical care or a diagnostic service. The publicly available edition includes the existing original guides and the source-reviewed guides deliberately registered for publication; other drafts are excluded.

## Updating

Export only the tested `dist/` files from the private source repository into the root of this public repository. Keep public-facing privacy statements, social preview URLs, and reading-list links accurate if the hosting domain changes. The source repository and the original ChatGPT Sites edition are separate; publishing here does not change either of them.

No store, online account system, analytics tracking, payment processing, or private coaching submission is provided in this static version.
